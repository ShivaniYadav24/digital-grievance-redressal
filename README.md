# Digital Grievance Redressal System

A web portal where citizens can submit complaints regarding public services.

## Tech Stack
- Frontend: React JS
- Backend: FastAPI (Python)
- Database: SQLite

## Features
- Complaint submission (Anonymous/Logged in)
- Unique Ticket ID generation
- Real-time status tracking
- Email notifications
- Admin dashboard
- Analytics dashboard
